VANTEMIO — public publication scope

Repository: https://github.com/pavlichuckcrypt-maker/Vantemio

blockchain-demo/contracts: NFT passport and test credits.
blockchain-demo/src: Base/Boson operations, tokenization, security checks, purchase recovery and protected delivery.
blockchain-demo/auditor-site: marketplace interface, accounts, seller inventory, asset uploads and order workspace.
blockchain-demo/test and auditor-site/*.test.mjs: executable engineering tests.
blockchain-demo/scripts: launch and verification workflows. Some configured workflows perform onchain actions; use npm test and npm run test:site for source verification.
blockchain-demo/evidence: historical sanitized testnet/fork reports.
tools: three adapters for validating accepted media and publication callbacks. AI editing, rendering and production orchestration are excluded.
docs and demo: workflow description, technical verification and MetaMask/Boson recording.

Excluded material includes the private AI engine and its history, wallet vaults, user databases, local operational state, machine-specific packaging utilities and internal application drafts. Public technical documents replace excluded drafts in the interface. Legacy document filenames remain unchanged for compatibility; their contents are in English.
