VANTEMIO — проверка публичного Base/Boson-модуля

Этот репозиторий содержит блокчейн-модуль и интерфейс marketplace, а не закрытый AI-монтажный движок. Исторические названия VidRa/AIMmontag сохранены в исходниках.

В корне репозитория: README.md — описание проекта; docs/DEMO_EVIDENCE.md — механизм и реальные testnet-транзакции; docs/VERIFICATION.json — результаты тестов; demo/ — запись MetaMask/Boson.

Проверка: Node.js 24.19 или новее, Python 3. В каталоге blockchain-demo выполнить npm ci, npm test, npm run test:site. Проверки используют временное локальное состояние; они не запускают производство фильма и не отправляют транзакции в сеть.

Просмотр интерфейса: из blockchain-demo выполнить npm run site. Сервер слушает только 127.0.0.1:18340. VIDRA_SITE_PORT позволяет выбрать другой свободный порт. VIDRA_MEDIA_HOME задаёт собственный каталог демо-медиа. При первом запуске создаётся собственная локальная база аккаунтов.

Приватные ключи, кошельки, базы пользователей и локальные медиаресурсы исходной машины не поставляются. Поэтому копия репозитория не подключается автоматически к прежним кошелькам или историческим заказам. Запись и отчёты доступны независимо от этих runtime-данных. Полный сценарий с новыми onchain-операциями требует отдельной настройки собственных тестовых кошельков и Base Sepolia; npm run demo:all не является командой проверки исходников.

Исходный код AI-студии закрыт. Контролируемый доступ для технической проверки можно запросить у команды.
