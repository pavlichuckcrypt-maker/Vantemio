VANTEMIO — reviewing the public Base/Boson module

This repository contains the blockchain module and marketplace interface. The proprietary AI video-production engine remains private. Historical VidRa/AIMmontag identifiers are retained in the source.

Repository overview: README.md describes the project; docs/DEMO_EVIDENCE.md explains the workflow and actual testnet transactions; docs/VERIFICATION.json records engineering checks; demo/ contains the MetaMask/Boson recording.

Source verification requires Node.js 24.19 or newer and Python 3. Inside blockchain-demo, run npm ci, npm test and npm run test:site. Tests use isolated temporary state and do not launch film production or send network transactions.

To inspect the interface, run npm run site from blockchain-demo. The server listens on 127.0.0.1:18340. VIDRA_SITE_PORT selects another available port. VIDRA_MEDIA_HOME selects a local demo-media directory. The first launch creates a new local account database.

Private keys, wallet vaults, user databases and original-machine media are excluded. A checkout therefore does not automatically connect to historical wallets or orders. The recording and reports can be reviewed independently of runtime state. New onchain operations require separately configured test wallets and Base Sepolia infrastructure; npm run demo:all is not a source-verification command.

Reviewers may request controlled access to the private AI studio from the team. Legacy document filenames are retained for interface compatibility; documentation is written in English.
